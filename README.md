## 🛠 Требования

### Окружение (один раз на машине)

Глобальная переменная `HOME_1C` — корень данных 1С на этой машине: инфобазы и
выгрузки лежат ВНЕ репозитория. Задаётся в `~/.zshrc`:

```bash
export HOME_1C="$HOME/1C"
```

Слово `export` обязательно: `bin/*.sh` запускаются как дочерние процессы и без
экспорта переменную не увидят. После правки откройте новый терминал (или
выполните `source ~/.zshrc`). Если `HOME_1C` не задана, процедуры останавливаются
с понятным сообщением, а не работают с путём `/IB/...` в корне файловой системы.

Вне репозитория, в `$HOME_1C`:

```
$HOME_1C/
 └── IB/
    ├── ground/            # файловая ИБ          (IB_PATH)
    └── DUMP/ground/       # выгрузка для разбора (DUMP_DIR)
```

Имя ИБ — имя проекта в lowercase. Имя проекта `dump` (в любом регистре)
зарезервировано: на регистронезависимой ФС (macOS) оно совпало бы с `IB/DUMP`.

## ⚙️ Переменные (bin/.env)

`bin/.env` создаётся из `bin/.env.example` и читается всеми процедурами `bin/`.

| Переменная | Значение |
|---|---|
| `HOME_1C` | глобальная, из `~/.zshrc` (не задаётся в `.env`, только проверяется) |
| `IB_NAME` | имя ИБ (по умолчанию — имя проекта в lowercase) |
| `IB_PATH` | `$HOME_1C/IB/$IB_NAME` — файловая ИБ |
| `DUMP_DIR` | `$HOME_1C/IB/DUMP/$IB_NAME` — выгрузка для разбора |
| `DESIGNER_BIN` | исполняемый файл платформы; задаётся вручную под каждую машину |
| `IB_USER`, `IB_PASSWORD` | пользователь ИБ (можно оставить пустыми) |

## 🧰 Процедуры bin/

| Процедура | Что делает | Лог (`var/log/`) |
|---|---|---|
| `create_ib.sh` | создаёт пустую файловую ИБ в `IB_PATH`; если ИБ уже есть — отказывается | `create_ib.log` |
| `dump_ib.sh` | выгружает конфигурацию ИБ в `DUMP_DIR` (вне git: для разбора и экспериментов) | `dump_ib.log` |
| `remove_ib.sh` | удаляет ИБ из `IB_PATH`; требует подтверждения (`-y` — без запроса) | `remove_ib.log` (дописывается) |
| `pull.sh` | ИБ → `src/1c` (источник истины, под git) | `pull.log` |
| `push.sh` | `src/1c` → ИБ | `push.log` |

`dump_ib.sh` и `pull.sh` вызывают одну и ту же команду платформы, но кладут
результат в разные места: `pull.sh` — в `src/1c`, `dump_ib.sh` — в `DUMP_DIR`.
Ни одна из процедур каталог выгрузки не очищает: файлы объектов, удалённых в ИБ,
остаются от прежней выгрузки.

Лог Конфигуратора (`/Out`) перезаписывается при каждом запуске; при ошибке
процедура печатает его содержимое сама. `remove_ib.sh` ведёт журнал с датами.

`remove_ib.sh` удаляет только каталог ИБ внутри `$HOME_1C/IB/` (и только если в
нём есть `1Cv8.1CD`). Запись об ИБ в списке баз стартера платформы и выгрузки в
`DUMP_DIR` он не трогает.

## 🚀 Быстрый старт

### Разово для новой ИБ

```bash
# 1) Локальные пути: раскомментируйте нужную строку DESIGNER_BIN
cp bin/.env.example bin/.env
```

```bash
# 2) Создайте пустую файловую ИБ из командной строки (ручной Конфигуратор не нужен)
./bin/create_ib.sh
```

3) Язык конфигурации — разовая ручная настройка. Без параметра `/L ru` новая
конфигурация получает язык English (наблюдение на 8.5.1.1529; параметр `Locale`
в строке соединения язык конфигурации не меняет). Язык фиксируется при первом
обращении Конфигуратора, поэтому до этого шага не запускайте `pull.sh` и `dump_ib.sh`:

```bash
source bin/.env
"$DESIGNER_BIN" /L ru &
```

- добавьте новую ИБ в список информационных баз (путь — `IB_PATH`)
- запустите Конфигуратор → «Открыть конфигурацию» → «Общие» → «Языки»
- при необходимости добавьте язык English (код `en`)
- сохраните конфигурацию и выйдите из платформы

```bash
# 4) Заберите конфигурацию в src/1c
./bin/pull.sh

# проверка: в src/1c/Languages/ есть Русский.xml
ll src/1c/Languages 
.  ..  English.xml  Русский.xml

# а в src/1c/Configuration.xml — <ScriptVariant>Russian</ScriptVariant>
g "<ScriptVariant>Russian</ScriptVariant>" src/1c/Configuration.xml 
			<ScriptVariant>Russian</ScriptVariant>
```

### Ежедневная работа

```bash
# правьте .bsl в VS Code, затем накатите изменения в ИБ:
./bin/push.sh

# посмотреть, что лежит в ИБ, не трогая src/1c:
./bin/dump_ib.sh
```

### Начать с чистой ИБ

```bash
./bin/remove_ib.sh     # спросит подтверждение (введите имя ИБ)
./bin/create_ib.sh     # затем снова шаги 3–4 выше
```

## 🩺 Если что-то не работает

- `HOME_1C не задана` — см. раздел «Окружение»; проверьте `echo $HOME_1C` в том же терминале.
- Ошибка Конфигуратора — процедура сама печатает лог; он же лежит в `var/log/`.
- `DESIGNER_BIN не найден` — поправьте путь в `bin/.env`
  (`find /opt -maxdepth 4 -name '*1cv8*'`).
